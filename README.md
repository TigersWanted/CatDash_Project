# Cat Dash

Cat Dash is a web-based game developed as a team project for a web development course at UC Merced.

## Overview

An endless-runner-style game where players control a cat, avoid falling off, and collect coins. The project includes a Flask backend, interactive JavaScript gameplay, and a SQL database for storing player information and leaderboard data.

## Technologies

- Python
- Flask
- JavaScript
- HTML/CSS
- SQL
- Git/GitHub

## Features

- Interactive browser-based gameplay
- Coin collection system
- Player leaderboard
- Persistent data storage
- Abilities inventory/store
